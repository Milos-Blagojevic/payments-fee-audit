payments-fee-audit report site

Try the contract extraction

The project reads payment-provider contracts written as prose and turns them back into contract YAML with …. This page sends the same prompt and JSON schema as python -m feeaudit.extraction extract, from your browser and on your own Puter account. You get a draft contract file in which every term is approved: false. Nobody has reviewed it, and the fee engine refuses it until a person does.

Before you extract

  • Where the text goes. The contract text you extract, a sample or what you paste, is sent to Puter (puter.com), and from Puter to Anthropic, which runs the model. Nothing goes to this site's owner.
  • Who pays. The call runs on your Puter account and is charged to it (Puter's user-pays model). This site holds no API key and pays nothing.
  • What it costs. At Anthropic's list prices, each of the five sample extractions cost USD … in the recorded runs. Puter charges its own rates, which may differ. Until the call ends, Puter holds the most it could cost (up to … output tokens) against your balance.
  • What to send. The samples are synthetic: the merchant Fernway and its providers are fictional. Do not paste a confidential contract.

      How this differs from the Python run
      
      
        
    • Same system prompt, documents, task, JSON schema, model and max_tokens
          (…). The data comes from python -m feeaudit.extraction export.
      • 
        
    • The request goes through Puter, pinned to Anthropic (provider: "claude",
          fallback: false). The page checks that Puter lists the model and stops if it does not.
      • 
        
    • Effort is not sent: Puter documents no effort option for Anthropic models, so the model's default effort
          applies. The Python run sends …. Thinking is left at the model's default in both.
      • 
        
    • No token count, no budget and no spend ledger: Puter bills your account, and the cost shown is Puter's.
      • 
        
    • The result is checked against the full contract_schema.json. The loader's further checks (time
          zone, duplicate clauses, order of volume bands) run when the file is loaded with feeaudit.contracts.
      • 
        
    • Nothing is stored: not in this site, not in your Puter storage. The download is the only copy.
